# Session Retrospective

**Date**: 2026-08-19
**Duration**: ~90 minutes
**Focus**: ป้องกันการเพิ่ม QR ด้วย V1 ไม่ให้กระทบ hardcode เดิม และเตรียม Barcode Learning V2

## Summary

สร้างและ deploy Barcode Learning V2 ที่แยกข้อมูลและ fallback จาก V1 พร้อมล็อก V1 ให้เป็นแบบอ่านอย่างเดียวใน Production หลังตรวจหน้าเว็บจริงพบว่า V1 มี Regex กว้าง 13 รูปแบบและยังเพิ่มหรือลบได้ ซึ่งยืนยันความเสี่ยงที่ผู้ใช้รายงาน

## What We Built

- เพิ่ม Barcode Learning V2, API, audit, runtime fallback, Scanner Agent support และ migration `upgrade_v19_barcode_learning_v2.sql`
- คง V1/hardcode เป็นเส้นทางแรก; V2 ทำงานเฉพาะเมื่อ V1 หา Master ไม่พบ
- ล็อก UI และ API ของ V1: `POST`/`DELETE /api/settings/barcodes` ตอบ `410`; V1 ยังอ่านรายการเดิมได้
- Deploy Production ที่ `https://labstock-two.vercel.app` และยืนยันหน้า V1 read-only ด้วยบัญชีที่ล็อกอินจริง

## AI Diary (Required - 100+ words)

ช่วงแรกผมตีความความกังวลว่าเป็นเพียง QR เก่าที่ต้องไม่ถูก V2 แทนที่ จึงเน้นลำดับ V1 ก่อน V2 และการแยกตารางข้อมูล แต่ผู้ใช้ชี้ให้เห็นกลไกที่สำคัญกว่า: การเพิ่ม Pattern V1 ใหม่สามารถเปลี่ยนการตีความของ QR ที่ flow เดิมและ hardcode พึ่งอยู่ได้ เมื่อเข้า Production และดูหน้าตั้งค่า พบ V1 จริง 13 รูปแบบ หลายตัวเป็น positional Regex ที่กว้าง และหน้าเดิมยังเปิดให้ Admin บันทึกหรือลบได้ ข้อสังเกตนี้ทำให้แนวทางที่ถูกต้องไม่ใช่ปิด V1 runtime เพราะจะเสี่ยงทำลายงานเดิม แต่ต้องแยก “การอ่าน” ออกจาก “การเขียน” โดยคง V1 สำหรับ compatibility และล็อก mutation ทั้ง UI และ API การทดสอบและ deploy ยืนยันว่าหน้า Legacy เหลือเพียงรายการ read-only แล้ว อย่างไรก็ดี V2 management/runtime ยังปิดอยู่ จึงต้องสื่อสารชัดว่าช่วงนี้ระบบหยุดรับ QR ใหม่เพื่อความปลอดภัย ไม่ใช่พร้อมใช้งาน V2 แล้ว

## Lessons Learned

- **Pattern**: ความเข้ากันได้ของ parser ไม่ได้วัดแค่ว่า V1 มาก่อน V2; ต้องป้องกันไม่ให้การเพิ่ม Regex ใหม่เข้าไปเปลี่ยนลำดับหรือผลการตีความของ legacy parser
- **Rollout**: ต้องตรวจหน้าจอและข้อมูลจริงใน Production เพราะ unit test ไม่เผยให้เห็นจำนวนและความกว้างของ Pattern V1 ที่ใช้งานอยู่
- **Safety**: ปิด write path ของ legacy ก่อนเปิด engine ใหม่ เป็นทางเลือกที่ปลอดภัยกว่าปิด runtime ของ legacy
