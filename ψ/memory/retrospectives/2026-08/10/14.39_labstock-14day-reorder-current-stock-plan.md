## Lessons Learned

- **Pattern**: Treat MAW session creation, engine readiness, prompt delivery, prompt submission, and visible response as separate verification gates.
- **Pattern**: The authoritative dispense signal is `logs.action = 'เบิกไปหน้างาน'`; exact-action filtering naturally excludes receipts, adjustments, reconciliation, and other non-usage records.
- **Pattern**: `/api/dashboard` already returns inventory totals per reagent, so current-stock UI can be added incrementally without a schema change or duplicate stock calculation.
- **Pattern**: When Local RAG retrieval is noisy, keep its historical evidence but verify current implementation details in the authoritative checkout.
