## Lessons Learned
- **Pattern**: ตรวจซ้ำเองเสมอ — รายงาน agent บอกผ่าน แต่รันจริงเจอ test timeout (PGlite แย่ง CPU) → แก้ที่ `vitest.config.ts` แทนการปัดว่า flaky
- **Pattern**: ซ้อม migration กับข้อมูลจริงบน branch แยก เจอสิ่งที่ test จำลองไม่เจอ (งานที่มีอยู่แล้ว) ให้หยุดถามก่อนรัน
- **Pattern**: โค้ดที่ deploy ก่อน migration ต้องอยู่หลัง flag และพิสูจน์ด้วย test นับ query ว่าปิด flag = เหมือนเดิม
- **Pattern**: branch ที่แยกจาก production ใช้รหัสผ่านชุดเดียวกัน → รัน SQL ผ่าน Neon tool พร้อม branch id แทนการดึง connection string
- **Anti-pattern**: อ่าน `ψ/WIP.md` ไม่ละเอียดตอนเริ่ม ทำให้ไม่รู้ข้อเท็จจริงที่บันทึกไว้แล้ว (`.env.local` → production)
- **Anti-pattern**: ใช้ Haiku ทำบัญชีโดยไม่สุ่มตรวจ — รายงานตารางที่ไม่มีจริง และค้นไม่ครบตามที่สั่ง
