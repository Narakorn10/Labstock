## Summary
แก้ LINE แจ้งเตือนใบสั่งซื้อให้ส่งเฉพาะ "Lab สั่งของใหม่ → Vendor" ครั้งเดียว ส่วนสถานะอื่นและการเตือนเกินกำหนดให้ดูในเว็บ (PR #32 merged)

- `src/lib/notification-outbox.ts`: การเตือนเกินกำหนดที่ retry มาช้าและสถานะ PO เปลี่ยนไปแล้วจะถูก SKIPPED แทนการส่ง

- `src/lib/barcode-runtime.ts`, `barcode-learning-auth.ts`, `activate/route.ts`: ถอด `BARCODE_LEARNING_V2_MANAGEMENT_ENABLED` / `RUNTIME_ENABLED` (เดิมกด Activate ได้ 409 เสมอเพราะ production ไม่มี RUNTIME flag)
- `src/components/qr-char-picker.tsx` + `src/lib/barcode-learning-v2-derive.ts`: แตะตัวแรก-ตัวสุดท้ายเพื่อกำหนด Item/Lot/Exp และ QR ชิ้นที่ 2 อ่านค่าเองจากตำแหน่งของชิ้นแรก ปุ่ม "บันทึกและเปิดใช้" ปุ่มเดียว และลบฉบับร่างที่ยังไม่เคยเปิดใช้ได้
- ตรวจ: tsc, eslint, build ผ่าน และ vitest 254/254 แต่ยังไม่ได้ลองกับ LINE จริงหรือ QR จริง

ปัญหา LINE ที่ผู้ใช้บอกว่า "มั่ว" ฟังดูกว้างมาก ผมเลยไปดูข้อมูลจริงใน `notification_outbox` ก่อน (อ่านอย่างเดียว) และเจอสาเหตุเป็นรูปธรรม 2 อย่าง คือ LINE เดียวผูกกับสองบัญชี (admin กับ 5783) และการเตือนที่ retry มาถึงช้าไปหนึ่งวันหลังใบถูกยกเลิก ถ้าผมเดาจากโค้ดอย่างเดียวคงไปแก้ผิดจุด
ส่วนเรื่อง QR ผู้ใช้พูดแค่ "Focus ที่เมนูสอนอ่าน QR Code" ผมเลยไม่ลงมือทันที แต่อ่านหน้าและสรุปให้ก่อน คำตอบ "V2 ยังไม่เปิดถาวร" ทำให้ผมไปเช็ก Vercel env และ Neon แล้วพบว่า production ไม่มี RUNTIME flag เลย ปุ่มเปิดใช้จึงไม่เคยใช้ได้จริง และตาราง V2 ก็ว่างเปล่า ข้อเท็จจริงนี้ทำให้ถอด flag ได้อย่างมั่นใจ เพราะหลัง deploy ผลการสแกนไม่เปลี่ยนจนกว่าจะมีคนเปิดใช้รูปแบบแรก
สิ่งที่ผมพลาดเกือบหลุดคือเงื่อนไขซ่อนใน `secondPreviewFailed` ที่ทำให้ตัวเลือกตัวอักษรหายไปทันทีที่ผู้ใช้แตะเลือก ผมจับได้ตอนทบทวนก่อนแทรกโค้ด
อีกเรื่องที่ไม่คาดคิดคือ local `main` ค้างตั้งแต่ ก.ค. และมี 5 commit ที่ไม่อยู่บน GitHub ผมจึงไม่ reset เองและถามผู้ใช้แทน

## Lessons Learned
- **Pattern**: คำว่า "แจ้งเตือนมั่ว" หรือ "ใช้ยาก" ต้องแปลงเป็นข้อเท็จจริงจากข้อมูลจริงก่อน (outbox rows, env ที่ตั้งจริง, จำนวน pattern) แล้วจึงออกแบบการแก้
- **Pattern**: feature flag ที่ไม่เคยถูกเปิดใน production มีผลเหมือนฟีเจอร์ไม่มีอยู่ ให้เช็ก `vercel env ls` ทุกครั้งที่ผู้ใช้บอกว่า "ยังไม่เปิดใช้"
- **Pattern**: logic ที่ต้องใช้ทั้งฝั่ง server และ client (เช่น derive regex) ต้องแยกเป็นโมดูลที่ไม่ import `@/lib/db`
- **Pattern**: ก่อนเขียนไฟล์ ψ ให้เช็กว่า branch ปัจจุบันตรงกับ origin หรือไม่ ถ้าไม่ตรงให้ใช้ worktree แยก
