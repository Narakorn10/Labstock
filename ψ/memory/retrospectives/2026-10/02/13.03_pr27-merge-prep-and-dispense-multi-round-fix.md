## Lessons Learned
- **Pattern**: ก่อนอธิบายว่า "ทำไมของยังไม่ขึ้น production" ให้เทียบ `origin/main` กับทุก branch ที่มีงานค้างทีเดียว ไม่ใช่แค่ PR ที่เปิดอยู่
- **Pattern**: คำสั่ง git ที่เปลี่ยน branch ต้องแยกจากคำสั่ง merge/commit และตรวจ `git branch --show-current` ก่อน
- **Pattern**: บั๊กเกี่ยวกับยอดสต็อก เขียนเทสต์ฐานข้อมูลจำลองให้ล้มก่อนแก้ แล้วค่อยแก้ ช่วยยืนยันสาเหตุจริง
- **Pattern**: lot เดียวกันถูกออกแบบให้แยกแถวตามวันที่รับ (`upgrade_v12_inventory_receive_rounds.sql`) การรวมยอดต้องทำที่ชั้นเบิก ไม่ใช่เปลี่ยนโครงสร้างตาราง
