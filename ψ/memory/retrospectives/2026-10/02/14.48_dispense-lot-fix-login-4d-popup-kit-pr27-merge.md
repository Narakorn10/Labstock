## Lessons Learned
- **Pattern**: กฎสต็อก/การเบิกเป็นระบบจริง ให้ถามว่า "อัตโนมัติหรือผู้ใช้เลือกเอง" ก่อนลงมือ ไม่เดา
- **Pattern**: ก่อนบอกว่า PR/งานยังไม่ได้ทำ ให้เช็กสาขาและ PR ที่มีอยู่ก่อน (PR #27 มี login 4d อยู่แล้ว)
- **Pattern**: ทำงานที่ working tree ผู้ใช้ไม่สะอาด ใช้ worktree แยก ห้าม stash ไฟล์ผู้ใช้; ใน worktree ต้อง `npm ci` ห้ามใช้ junction `node_modules` กับ Turbopack
- **Pattern**: ฟังก์ชันที่ shadow ชื่อ global (`confirm`) ทำให้โค้ดใหม่จากสาขาอื่นพังตอน merge — type check จับได้ ต้องรันหลังทุก merge
- **Pattern**: dev server พอร์ต 3100 ของผู้ใช้อาจแคชเก่าและตอบ 500 ให้ใช้ production build บนพอร์ตอื่นถ่ายภาพ
