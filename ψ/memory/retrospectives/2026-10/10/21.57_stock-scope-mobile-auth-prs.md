## Lessons Learned
- **Pattern**: ให้ผู้ตรวจพิสูจน์ "ข้ออ้างของ planner" เอง ก่อนทุกครั้ง — รอบนี้ผลคือขอบเขตแจ้งเตือนเล็กลงมาก
- **Pattern**: ลำดับ commit ต้องคำนึงถึง tsc และ coverage test ผ่านทุก commit (error code ต้องมาก่อนผู้ใช้; ลบออกจาก PENDING ใน commit เดียวกับที่ import scoped-db)
- **Pattern**: ฟังก์ชันที่รับ "ผู้ใช้ที่ยืนยันแล้ว" เสี่ยงถูกเรียกด้วย username จาก body — กันด้วยเทสต์สแกนข้อความตรง ๆ ไม่ใช่ regex ของ import
- **Pattern**: SQL fragment ว่างของ flag ปิดต้องพิสูจน์ด้วยการดัก SQL จริงเทียบข้อความเดิมตรงตัว (เทสต์ 11b) ไม่ใช่เชื่อว่า "น่าจะเหมือน"
- **Pattern**: PR ซ้อนสาย merge ตามลำดับแล้วต้องลบ branch ใบก่อนหน้า ไม่งั้นใบถัดไปไปรวมเข้า branch เดิม
