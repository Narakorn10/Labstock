## Lessons Learned
- **Pattern**: ก่อนรัน git ให้ยืนยันก่อนว่าโฟลเดอร์เป็น repo และเป็นโปรเจกต์ที่ถูกต้อง
- **Pattern**: ถ้าข้อมูลที่ต้องการยังไม่อยู่ใน session ให้ดูก่อนว่ามีคำขอที่มีอยู่แล้วส่งมาได้หรือไม่ เพื่อเลี่ยงการแตะ login/JWT
- **Pattern**: หน้าที่ต้อง login ด้วยสิทธิ์สูงตรวจด้วยภาพเองไม่ได้ ให้บอกผู้ใช้ให้ดูแทนการสรุปว่าผ่าน
- **Pattern**: เทสต์ฐานข้อมูลจำลองล้มสลับไฟล์ด้วย `Hook timed out in 10000ms` ตอนรันทั้งชุด แต่ผ่านเมื่อรันแยก ควรตั้ง `hookTimeout`
