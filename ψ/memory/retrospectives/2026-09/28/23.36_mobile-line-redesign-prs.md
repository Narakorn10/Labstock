## Lessons Learned
- **Pattern**: ก่อนอ้างว่า UI ตรงดีไซน์ ต้องเปิดเบราว์เซอร์จริงและเทียบภาพ ไม่ใช่แค่ผ่าน lint/tsc (จับได้: สีลิงก์ถูกกฎ `a{color}` ทับ, ปุ่มถูกบังด้วย dev badge)
- **Pattern**: กฎ `a { color }` ใน `globals.css` ไม่อยู่ใน layer ชนะ utility ของ Tailwind ต้องใช้ `text-ink!` กับลิงก์
- **Pattern**: หลังสลับ branch ถ้า dev server เสิร์ฟของเก่า ให้ตรวจ CSS ที่เสิร์ฟจริง (`curl` แล้ว grep) ก่อนเชื่อภาพ; แก้โดยย้าย `.next/dev/cache`
- **Pattern**: Fix ทุกอันต้องมีเทสต์ที่ล้มบนโค้ดเก่า (ทำโดยคืนไฟล์เก่าชั่วคราวแล้วรัน)
- **Pattern**: ผู้ใช้ตอบสั้น ๆ ว่า "เห็นด้วย" ต่อสรุปยาว ให้ยืนยันเฉพาะข้อที่เปลี่ยนความคาดหวัง (เช่น "desktop จะยังไม่เปลี่ยน") ด้วยประโยคเดียวแยกบรรทัด
- **Pattern**: `git diff origin/main` เทียบกับไฟล์ในเครื่อง (รวมไฟล์ยังไม่ commit) ต้องใช้ `origin/main...branch` เวลาสแกนความลับก่อน push
