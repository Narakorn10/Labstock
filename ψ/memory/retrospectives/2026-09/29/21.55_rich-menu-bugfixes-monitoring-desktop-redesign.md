## Lessons Learned
- **Pattern**: A SELECT with an aggregate and no FROM returns one row, so `COUNT(*)` is 1. Prove SQL suspicions with a tiny query before theorising.
- **Pattern**: Write the regression test first and confirm it fails on the old code (PGlite `*.db.test.ts`).
- **Pattern**: Re-theme at the framework layer (Tailwind `@theme` scales, tokens) before editing files; then screenshot every page, because global rules (link colour, `@layer` order) break in surprising places.
- **Pattern**: Screenshots of the real app with all `/api/**` mocked in the browser (playwright-core in the scratchpad) verify UI without touching the production database.
- **Pattern**: A route that catches an error and returns 400 leaves no server-side trace; log outcome + user + filtered input (`app_events`, allowlist, never raw body).
- **Process**: Stacked PRs: after merging, verify with `git merge-base --is-ancestor <commit> origin/main`.
- **Process**: Many repo files are CRLF; edit scripts must preserve the file's own EOL and be checked with node, not grep.
